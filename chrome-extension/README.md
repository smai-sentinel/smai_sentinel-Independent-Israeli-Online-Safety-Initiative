# SMAI AI Work Agent — Chrome

1. פתחו `chrome://extensions`.
2. הפעילו **מצב מפתח**.
3. לחצו **טעינת פריט שלא נארז** ובחרו בתיקייה `chrome-extension`.
4. לחצו על סמל התוסף ופתחו את חלונית SMAI AI.

ההרשאה לאתר מתבקשת בזמן השימוש. פעולות רגישות תמיד דורשות אישור מפורש. אין להזין סיסמאות, קודי אימות או פרטי תשלום בצ׳אט של הסוכן.
